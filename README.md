# 🚀 Personal Portfolio Website  

This is my **personal portfolio website** showcasing my work, experience, and skills as a **Frontend Web Developer & Fullstack Developer**. It is built with HTML, CSS, JavaScript, and Bootstrap.

---

## 🌟 Features  
✅ Fully responsive design  
✅ Animated sections with AOS library  
✅ Interactive timeline for experience  
✅ Smooth scrolling navigation  
✅ Optimized for performance  

---

## 📌 Technologies Used  
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap  
- **Animations:** AOS (Animate on Scroll)  
- **Version Control:** Git & GitHub  
- **Deployment:** Hosted on GitHub Pages / Vercel (Modify accordingly)
